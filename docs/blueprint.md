# **App Name**: QuizTime Champions

## Core Features:

- Admin Control: Admin panel to start the quiz, advance questions, and (optionally) view participants.  Uses a simple authentication mechanism (e.g., password check) for access.
- User Quiz Interface: User quiz interface with name entry, question display, answer submission, and waiting states.  Implements polling to update the UI based on the admin's actions.
- Real-Time Leaderboard: Real-time leaderboard displaying participant scores, ranked positions, and handling ties. Implements polling for score updates.

## Style Guidelines:

- Primary color: Teal (#008080) for a calm and focused atmosphere.
- Secondary color: Light gray (#F0F0F0) for backgrounds and neutral elements.
- Accent: Yellow (#FFC107) for important actions, buttons, and highlighting the current question.
- Clean, minimalist layout with clear sections for questions, options, and scores.
- Simple, clear icons for indicating correct/incorrect answers and leaderboard positions.
